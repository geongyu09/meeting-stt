# 작업 폴더 규칙

이 폴더는 사용자의 개인 비서가 쓰는 작업 폴더다. 비서는 사용자의 자료를 읽고 정리하며, 사용자에 대해 알게 된 것을 이 폴더에 쌓는다.
Claude Code(`CLAUDE.md`가 이 파일을 불러온다)와 Codex가 이 파일을 함께 읽는다. 규칙을 바꾸려면 이 파일과 `.agents/skills/`를 고친다.

## 먼저 읽을 것

- `profile/index.md`: 사용자 정보의 색인이다. 사용자에 대한 정보가 필요하거나 사용자의 입장을 짐작해야 할 때는 색인을 보고 관련 파일을 읽는다.
- `profile/communication/style.md`: 사용자의 문체다. 답변하거나 글을 쓰기 전에 반드시 읽고 따른다.

Claude Code는 `CLAUDE.md`가 두 파일을 자동으로 불러온다. 다른 에이전트는 대화를 시작할 때 두 파일을 먼저 읽는다.

## 폴더 구조

```
/
├── AGENTS.md          # 이 파일 (규칙 본문)
├── CLAUDE.md          # Claude Code용 진입 파일 (이 파일을 불러온다)
├── tasks.md           # 마감이 있는 할 일
├── tasks-done.md      # 끝난 할 일 보관
├── backlog.md         # 마감 없는 공부 목록
├── raw/               # 정제되지 않은 모든 문서
│   └── recordings/    # 녹음 원문 (앱이 저장한다)
├── wiki/              # 정리된 지식 (index.md 목차, log.md 이력)
├── docs/              # 프로젝트별 작업 노트 (docs/<slug>/index.md)
├── profile/           # 사용자 정보 (index.md 색인, _history/ 변경 이력)
└── .agents/skills/    # 요청별 절차 (.claude/skills/는 같은 폴더를 가리키는 링크)
```

- 폴더 이름은 영어로 짓는다. 파일 이름은 목록만 보고도 내용을 알 수 있게 날짜나 주제를 넣는다.
- 폴더 맨 위에는 위에 적힌 파일 말고는 새로 만들지 않는다.

## 저장 위치

사용자를 위해 만든 문서는 아래 표에서 먼저 위치를 찾고, 해당하는 곳이 없으면 `raw/`에 둔다.

| 내용                                    | 위치                                          | 절차                 |
| --------------------------------------- | --------------------------------------------- | -------------------- |
| 정리된 지식과 개념                      | `wiki/<카테고리>/<제목>.md`                   | `wiki` 스킬          |
| 사용자에 대한 오래가는 사실             | `profile/<영역>/<주제>.md`                    | `profile` 스킬       |
| 사용자의 문체                           | `profile/communication/style.md`              | `style` 스킬         |
| 일일 회고                               | `profile/retrospective/YYYY/MM/YYYY-MM-DD.md` | `retrospective` 스킬 |
| 프로젝트별 요구사항, 결정, 산출물, 회고 | `docs/<slug>/`                                | `project` 스킬       |
| 마감이 있는 할 일                       | `tasks.md`                                    | `todo` 스킬          |
| 마감 없이 나중에 공부할 주제            | `backlog.md`                                  | 아래 "요청별 행동"   |
| 그 밖의 모든 문서                       | `raw/`                                        |                      |

`raw/`에는 정제되지 않은 문서가 모두 들어간다. 사용자가 넣은 자료, 비서가 쓴 메모와 질문 목록, 글의 개요(`raw/[outline] 제목.md`)와 초안(`raw/[draft] 제목.md`), 녹음 원문(`raw/recordings/`)이 여기에 있다.

- 비서도 `raw/`를 읽고 쓴다. 다만 사용자가 넣은 자료와 녹음 원문의 본문은 사용자가 요청하지 않으면 고치지 않는다.
- `raw/`의 내용을 정리해 `wiki/`나 `docs/`로 보내면, 정리한 문서의 출처에 `raw/` 파일 경로를 적는다.
- 잠깐 쓰고 버릴 작업 파일은 이 폴더가 아니라 임시 폴더에 둔다.

## 요청별 행동

| 사용자가 이렇게 말하면                                                        | 할 일                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 할 일 추가, 완료, 취소, 마감 변경, 할 일 확인, "오늘 뭐 하지"                 | `todo` 스킬                                                                                                                                                                                                                                         |
| 자기 자신에 대한 새 사실이나 바뀐 사실                                        | `profile` 스킬 (저장하기 전에 한 줄로 확인받는다)                                                                                                                                                                                                   |
| 답변이나 글의 말투, 표현을 고쳐 달라는 말 ("이런 말 쓰지 마", "더 짧게 답해") | `style` 스킬                                                                                                                                                                                                                                        |
| 자료(파일, URL, 붙여넣은 글)를 정리해 달라는 말, 위키 점검                    | `wiki` 스킬                                                                                                                                                                                                                                         |
| 새 프로젝트, 프로젝트 상태 갱신, 프로젝트 종료                                | `project` 스킬                                                                                                                                                                                                                                      |
| 글의 초안, 개요, 뼈대                                                         | `draft` 스킬                                                                                                                                                                                                                                        |
| 회고, 오늘 마무리                                                             | `retrospective` 스킬                                                                                                                                                                                                                                |
| 녹음 원문 정리                                                                | `recording` 스킬                                                                                                                                                                                                                                    |
| "나중에 공부해야지", "백로그에 추가"                                          | `backlog.md`의 알맞은 섹션에 한 줄로 추가한다. 분류가 애매하면 되묻지 않고 `## 미분류`에 넣는다. 마감이 생기면 `tasks.md`로, 공부해서 정리하면 `wiki/`로 보내고 여기서 지운다                                                                       |
| "기억해줘", "정리해둬"                                                        | 저장 위치 표에 따라 이 폴더 안에 파일로 저장하고, 답변에 그 경로를 적는다                                                                                                                                                                           |
| "~가 뭐야" 같은 지식 질문                                                     | `wiki/index.md`를 보고 `wiki/`를 검색해 관련 페이지를 먼저 찾는다. 있으면 그 페이지를 바탕으로 답하고 참고한 경로를 밝힌다. 없으면 일반 지식으로 답하고 위키에 없는 주제라고 한 줄 알린다. 코드 디버깅, 파일 작업, 방금 대화의 후속 질문은 제외한다 |

- 메시지가 `/<이름>`이나 `$<이름>`으로 시작하면 `.agents/skills/<이름>/SKILL.md`를 읽고 그 절차를 따른다.
- `tasks.md`와 `backlog.md`는 관련 요청이 있을 때만 읽는다.

## 문체

- 답변과 글쓰기 모두 `profile/communication/style.md`를 따른다. 비서의 답변은 `## 답변`을, 사용자 대신 쓰는 글(메모, 위키, 회고, 메일, 블로그 등)은 `## 글쓰기`를 먼저 보고, `## 쓰지 않는 표현`은 둘 다 지킨다.
- 파일에 적히지 않은 부분은 짐작으로 채우지 않고 평이하게 쓴다.
- 사용자가 표현을 직접 고치라고 하면 `style` 스킬로 바로 기록한다. 사용자의 글에서 반복되는 패턴을 발견하면 기록할지 한 줄로 묻는다.

## 운영 원칙

- 사실과 추정을 구분해서 적는다. 추정이면 추정이라고 밝힌다.
- 파일 하나에는 주제 하나만 담는다.
- `profile/` 파일 본문에는 현재 사실만 두고, 바뀐 이력은 `profile/_history/<영역>-<파일명>.md`에 한 줄씩 남긴다.
- `profile/`은 사용자 확인 없이 고치지 않는다. 사용자가 직접 지시한 문체 기록(`style` 스킬)만 예외다. 일시적인 감정이나 기분은 저장하지 않는다.
- 상대 날짜("내일", "이번 주 금요일")는 저장할 때 `YYYY-MM-DD (요일)`로 바꾼다. 오늘 날짜는 대화에 주어진 날짜를 쓰고, 없으면 `date` 명령으로 확인한다.
- 파일을 옮기거나 지웠으면 무엇을 어디로 옮겼는지 답변에 적는다.
- 질문이 필요하면 답변 글에 번호 목록으로 묻고 사용자의 다음 메시지를 기다린다.
- 사용자가 없는 자동 실행(녹음 정리, 루틴)에서는 묻지 않고 끝까지 처리하고, 확인이 필요한 일은 결과에 "확인 필요"로 남긴다.
