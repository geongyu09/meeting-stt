# 문체

> 비서가 사용자에게 답하거나 사용자 대신 글을 쓸 때 따르는 사용자의 문체다.
> 사용자가 직접 말한 것과 사용자의 글에서 반복해서 관찰된 것만 적는다. 비어 있는 항목을 일반론으로 채우지 않는다. 기록하는 절차는 `style` 스킬을 따른다.

## 답변

비서가 사용자에게 답할 때의 말투(존댓말, 반말), 길이, 형식이다.

_(아직 기록 없음)_

## 글쓰기

사용자 대신 쓰는 글(메모, 위키, 회고, 메일, 블로그 등)의 문체다. 글 종류마다 다르면 `### 위키`처럼 나눈다.

_(아직 기록 없음)_

## 쓰지 않는 표현

답변과 글 모두에서 쓰지 않는 표현이다. 한 줄에 하나씩 적고, 대신 쓸 표현이 있으면 함께 적는다.

_(아직 기록 없음)_
