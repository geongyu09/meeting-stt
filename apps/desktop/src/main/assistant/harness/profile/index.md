# 사용자 정보

> 비서가 사용자에 대해 알게 된 오래가는 사실을 모은다. 저장하기 전에 사용자에게 확인받고, 절차는 `profile` 스킬을 따른다.
> 파일 하나에는 주제 하나만 담고, 본문에는 현재 사실만 둔다. 바뀐 이력은 `_history/<영역>-<파일명>.md`에 한 줄씩 남긴다.
> 파일은 처음 저장할 때 만들고, 새 파일을 만들면 아래 "파일" 목록에 한 줄을 더한다.

## 영역

| 영역             | 담는 것               | 파일 예                                                                                                              |
| ---------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `identity/`      | 잘 바뀌지 않는 정체성 | `basic.md` (이름, 하는 일, 사는 곳), `values.md` (가치관, 우선순위), `personality.md` (성격, 강점, 약점)             |
| `work/`          | 일과 학습             | `current.md` (지금 하는 일, 진행 중인 프로젝트), `history.md` (경력, 학력), `skills.md` (기술, 도구, 배우는 중인 것) |
| `lifestyle/`     | 생활                  | `routine.md` (하루 일과), `habits.md` (습관), `health.md` (운동, 컨디션)                                             |
| `mind/`          | 생각                  | `goals.md` (목표), `interests.md` (관심사), `relationships.md` (주변 사람), `insights.md` (경험에서 얻은 교훈)       |
| `communication/` | 소통                  | `style.md` (문체, 답변과 글쓰기가 따른다)                                                                            |
| `retrospective/` | 일일 회고             | `index.md` (날짜별 색인), `YYYY/MM/YYYY-MM-DD.md`                                                                    |

헷갈리기 쉬운 영역은 이렇게 나눈다.

- `identity/values.md`는 원래 가진 신념이고, `mind/insights.md`는 경험에서 얻어 근거(어떤 경험)를 함께 적는 교훈이다.
- `work/skills.md`는 "새 도구를 배웠다" 같은 사실이고, `mind/insights.md`는 다른 일에도 적용할 수 있게 일반화한 교훈이다.
- `mind/goals.md`는 앞으로 할 것이고, `mind/insights.md`는 지금까지 얻은 관점이다.
