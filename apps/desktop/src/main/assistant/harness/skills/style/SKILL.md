# 문체 기록

사용자마다 문체가 다르다. 비서는 `profile/communication/style.md`에 사용자의 문체를 쌓고, 답변과 글쓰기 모두 그 파일을 따른다.

## 파일 구조

- `## 답변`: 비서가 사용자에게 답할 때의 말투(존댓말, 반말), 길이, 형식(목록, 표를 쓰는지)이다.
- `## 글쓰기`: 사용자 대신 쓰는 글의 문체다. 글 종류마다 다르면 `### 위키`, `### 회고`, `### 메일`처럼 하위 섹션으로 나눈다. 좁은 상황의 규칙이 공통 규칙보다 우선한다.
- `## 쓰지 않는 표현`: 답변과 글 모두에서 쓰지 않는 표현이다. 한 줄에 하나씩 적고, 대신 쓸 표현이 있으면 `- 결론적으로 (쓰지 않음)`, `- ~를 진행했습니다 → ~했습니다`처럼 함께 적는다.

항목을 처음 채우면 그 섹션의 `_(아직 기록 없음)_` 줄을 지운다.

## 기록하는 경우

1. 사용자가 직접 지시하면 바로 기록한다. "이런 말 쓰지 마", "앞으로 짧게 답해"처럼 사용자가 정한 것이므로 묻지 않고 알맞은 섹션에 적은 뒤, 답변에 기록한 줄과 위치를 알린다. 같은 내용이 이미 있으면 새로 적지 않고 그 줄을 고친다.
2. 사용자가 비서의 글을 직접 고쳐 주면, 고친 전후를 비교해 반복될 만한 규칙이 있는지 본다. 있으면 "이 규칙을 문체에 기록할까요?"라고 한 줄로 묻고, 동의하면 적는다.
3. "내 글 보고 문체 정리해줘"처럼 사용자가 글을 주면, 그 글에서 여러 번 반복되는 패턴만 뽑는다(문장 길이, 종결 어미, 자주 쓰는 연결어, 쓰지 않는 표현, 제목과 목록 쓰는 방식). 뽑은 목록을 보여 주고 사용자가 고른 것만 적는다.

## 기록하지 않는 것

- 한 번만 보인 습관이나 짐작은 적지 않는다. 사용자가 실제로 말했거나 사용자의 글에서 반복해서 관찰된 것만 적는다.
- 비어 있는 섹션을 일반적인 글쓰기 원칙으로 채우지 않는다.

## 적용

- 답하거나 글을 쓰기 전에 이 파일을 읽는다. Claude Code는 `CLAUDE.md`가 자동으로 불러온다.
- 글을 다 쓴 뒤 `## 쓰지 않는 표현`의 표현이 들어갔는지 확인하고, 들어갔으면 고친 뒤 내보낸다.
- 이 파일은 `profile/`에 있지만, 사용자가 직접 지시한 기록은 확인 없이 고쳐도 된다. 바꾼 이력은 `profile/_history/communication-style.md`에 한 줄씩 남긴다.
