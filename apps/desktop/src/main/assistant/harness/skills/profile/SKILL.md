# 사용자 정보 갱신

`profile/` 아래 파일에 사용자에 대한 사실을 쌓는다. 영역과 파일 구분은 `profile/index.md`를 따른다. 문체 기록은 이 스킬이 아니라 `style` 스킬이 한다.

## 저장할 것과 하지 않을 것

- 저장한다: 오래가는 사실과 패턴. 예를 들어 사는 곳, 하는 일, 진행 중인 프로젝트, 새로 배우기 시작한 기술, 생긴 습관과 끊은 습관, 목표, 가치관의 변화, 경험에서 얻은 교훈이 해당한다.
- 저장하지 않는다: 일시적인 감정이나 기분, 지나가는 말, 사용자가 "그냥 얘기하는 거야"라고 한 내용이다.
- 기술 이름을 말했다고 해서 배우는 중인 것은 아니다. "배우고 있어", "공부 중이야"처럼 진행 중이라고 말할 때만 저장한다.
- 매번 끼어들지 않는다. 확실히 저장할 가치가 있는 사실에만 한 번씩 제안한다.

## 절차

1. 저장할 파일을 고른다. `profile/index.md`의 영역표를 보고, 맞는 파일이 없으면 영역 안에 주제 이름으로 새 파일을 정한다.
2. 그 파일이 있으면 읽고 현재 내용과 비교한다.
3. 사용자에게 한 줄로 확인받는다. 바꾸는 경우에는 전후를 보여 준다.
   > `profile/work/current.md`의 "지금 하는 일"을 "A사 프론트엔드 개발"로 바꿀까요?
4. 동의하면 본문을 고친다. 본문에는 현재 사실만 두고 `## 변경 이력` 같은 섹션을 만들지 않는다.
5. 이력 파일 `profile/_history/<영역>-<파일명>.md`(경로의 `/`를 `-`로 바꾼 이름, 예: `work/current.md` → `_history/work-current.md`)의 맨 아래에 `- YYYY-MM-DD: 바꾼 내용 요약` 한 줄을 더한다. 파일이 없으면 `# 변경 이력: <영역>/<파일명>.md` 제목으로 만든다.
6. 새 파일을 만들었으면 `profile/index.md`의 "파일" 목록에 한 줄을 더한다.

## 형식

- 사실과 추정을 구분한다. 추정이면 "(추정)"을 붙인다.
- `mind/insights.md`의 교훈은 근거가 된 경험과 함께 적는다.

  ```markdown
  ### {짧은 제목}

  - 교훈: {한 문장}
  - 배경: {어떤 경험에서 나왔는지, 회고에서 나왔으면 파일 경로}
  - 적용: {앞으로 어디에 쓰는지}
  - 날짜: YYYY-MM-DD
  ```

## 사용자가 없는 자동 실행에서

녹음 정리나 루틴처럼 확인받을 사람이 없으면 `profile/`을 고치지 않는다. 대신 결과에 "확인 필요: profile 후보" 목록으로 남기고, 사용자가 다음 대화에서 고르게 한다.
